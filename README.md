# TaskFlow

Um gerenciador de tarefas simples desenvolvido para praticar desenvolvimento web e JavaScript.

## 📌 Sobre o projeto

O **TaskFlow** permite criar, editar e excluir tarefas de forma simples e intuitiva.

O projeto foi desenvolvido como parte dos meus estudos em programação, com foco em colocar em prática conceitos de **HTML, CSS e JavaScript**.

## 🚀 Funcionalidades

- Adicionar tarefas
- Editar tarefas
- Excluir tarefas
- Listar tarefas
- Salvar tarefas no navegador com `localStorage`

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 📂 Estrutura do projeto

```text
taskflow/
├── index.html
├── index.css
├── javascript.js
└── README.md
```

## ▶️ Como executar

1. Clone este repositório:

```bash
git clone https://github.com/melissalcs/taskflow.git
```

2. Abra a pasta do projeto.

3. Abra o `index.html` no navegador ou utilize o **Live Server** no VS Code.

## 🎯 Objetivo

O objetivo do projeto é desenvolver e aprimorar conhecimentos em JavaScript, manipulação do DOM, eventos e armazenamento de dados no navegador.
